# راهنمای کار روی پروژه آموزگار

این راهنما برای همهٔ تغییرات این پروژه است. گراف پایدار در `graphify-out/graph.json` و تاریخچهٔ کار در `اسکیل/CHANGES.md` نگهداری می‌شود.

## شروع یا بازیابی کانتکست

- پس از شروع جلسه یا خلاصه‌شدن کانتکست، ابتدا همین فایل، `اسکیل/CONTEXT.md` و آخرین ورودی‌های `اسکیل/CHANGES.md` را بخوان.
- برای سؤال فعلی `npm run graph:query -- "<question or symbol>" --budget 1500` اجرا کن. برای نام‌های کد، نام دقیق انگلیسی نتیجهٔ بهتری می‌دهد.
- برای بررسی یک مفهوم `npm run graph:explain -- "App"` و برای مسیر ارتباطی `scripts/graphify.cmd path "A" "B"` را اجرا کن.
- کل پروژه یا کل JSON گراف را وارد کانتکست نکن. فقط فایل‌ها و بخش‌هایی را بخوان که خروجی گراف برای کار فعلی مشخص کرده است. گزارش `graphify-out/GRAPH_REPORT.md` فقط برای دید کلی معماری است.
- گراف نقشهٔ راه است؛ قبل از ویرایش، خطوط فعلی فایل‌های مرتبط را بررسی کن. اگر پرس‌وجو نتیجه نداشت، جست‌وجوی محدود روی نام یا مسیر مربوط انجام بده.

## انجام تغییرات

- پیش از تغییر، با گراف ارتباطات و اثر تغییر بر اجزای مرتبط را بررسی کن.
- پس از تغییر کد، `npm run graph:update` را اجرا و یک پرس‌وجوی مرتبط را بررسی کن. برای بازسازی اولیه از `npm run graph:build` استفاده کن؛ این فرمان فقط AST محلی است و API نیاز ندارد.
- برای تغییرات رابط یا برنامه، بررسی متناسب با همان تغییر را انجام بده؛ اگر وابستگی‌ها نصب‌اند، `npm run lint` و `npm run build` در دسترس‌اند.
- هر نوبت تغییر را در `اسکیل/CHANGES.md` با تاریخ، هدف، فایل‌های تغییرکرده، نتیجهٔ بررسی و کار باقی‌مانده ثبت کن. وضعیت جاری و تصمیم‌های لازم برای ادامه را کوتاه در `اسکیل/CONTEXT.md` به‌روز کن.
- پیش از خلاصه‌شدن کانتکست، هدف جاری، اقدامات انجام‌شده و قدم بعدی را در `اسکیل/CONTEXT.md` ذخیره کن. در ادامه، از همین وضعیت و پرس‌وجوی گراف استفاده کن.

## ابزار و محدوده

- برای کامیت‌ها، طبق ترجیح مالک نام مدل عامل و سطح اجرای واقعی آن (مثل light یا high) را در هویت نویسنده بیاور؛ فقط مقادیر معلوم را بنویس و مدل یا سطح نامعلوم را حدس نزن. از ایمیل محلی `codex@local.invalid` استفاده کن؛ هویت را برای همان فرمان کامیت تنظیم کن تا عوامل بعدی هویت خودشان را ثبت کنند.

- Graphify رسمی نسخهٔ `0.9.100` در `.tools/graphify` نصب می‌شود؛ راه‌اندازی مجدد: `npm run graph:setup`.
- راهنمای رسمی ابزار در `.codex/skills/graphify/SKILL.md` است؛ فرمان‌های آن را با `scripts/graphify.cmd` اجرا کن، چون نصب این پروژه محلی است.
- `Images/` و `images/` در Git نادیده گرفته می‌شوند. فایل‌های برنامه در `public/assets/` همچنان قابل ثبت در Git هستند.
- گراف فعلی برای کد و ارتباطات ایستا ساخته می‌شود؛ تحلیل معنایی تصاویر، ویدئو و اسناد جزو آن نیست.
