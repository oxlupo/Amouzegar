# وضعیت جاری

- پروژه: فروشگاه زیورآلات آموزگار با React، TypeScript و Vite.
- محیط فعلی: Windows / PowerShell؛ فرمان‌های Graphify از ریشهٔ پروژه اجرا شوند.
- درخواست مالک: استفاده از گراف برای فهم و ادامهٔ کار؛ خودداری از بازخوانی کل پروژه پس از پرشدن کانتکست؛ ثبت همهٔ تغییرات در پوشهٔ «اسکیل».
- ابزار Git از قبل نصب بود؛ مخزن محلی برای پروژه ایجاد شده است. مالک ثبت همهٔ فایل‌های غیرنادیده‌گرفته‌شده را در اولین کامیت درخواست کرده است. remote ایجاد نشده است.
- ترجیح مالک برای نویسندهٔ کامیت: نام مدل عامل و سطح اجرای واقعی آن، در صورت معلوم‌بودن. این نشست: `Codex (GPT-6)`، ایمیل محلی `codex@local.invalid`؛ سطح دقیق اجرا در دسترس نیست و حدس زده نمی‌شود.
- ابزار Graphify به‌صورت محلی نصب و مهارت رسمی Codex در پروژه ثبت شده است.
- نقشهٔ کد: `graphify-out/graph.json`؛ مشاهدهٔ بصری: `graphify-out/graph.html`؛ پرس‌وجو: `npm run graph:query -- "App"`.
- راه‌اندازی کامل شد؛ ساخت، به‌روزرسانی و پرس‌وجوی گراف و قواعد نادیده‌گرفتن تصاویر بررسی شدند. کار برنامه‌نویسی باز از این درخواست باقی نمانده است.
- مالک هر دو اصلاح را صریحاً تأیید کرد. فایل مهارت سراسری Claude از `SKILL.md.bak` به نسخهٔ `0.9.46` برگردانده شد؛ برابری SHA256 فایل و نسخهٔ پشتیبان تأیید شد.
- ویندوز تغییر مالکیت `.git` از حساب sandbox را با Access denied رد کرد. برای رفع خطای Git، فقط مسیر دقیق `E:/New folder/Amouzegar` در `safe.directory` تنظیمات Git حساب کاربر ثبت شد. اجرای عادی `git status` و نادیده‌گرفتن تصاویر موفق است؛ مالکیت فایل‌ها تغییر نکرد.
